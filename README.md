**Prerequisites to execute script:**
1. Maven.
2. Java 1.8 or higher version.

**Steps to execute script:**

**Method 1:**
1. In any command terminal navigate to the folder which contains pom.xml file.
2. Run below command:

    1) **mvn clean test**

**Method 2:**
1. import the project to any IDE.
2. Right click on pom.xml
3. Run pom.xml

**Method 3:**
1. import the project to any IDE.
2. Right click on testNG.xml
3. Run testNG.xml
